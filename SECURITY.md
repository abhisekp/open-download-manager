# Security reporting

Do not include tokens, cookies, credential-bearing URLs, private download history or personal files in a public issue. Contact the repository owner through their GitHub profile to arrange a private disclosure channel. Dedicated private reporting and response-time commitments are not configured or claimed yet.

ODM is early development. Keep its UI bound to loopback. Do not expose the port to the network or treat the local API as a hosted multi-user service. Browser pairing tokens grant link submission only and can be revoked from Settings. Dependency scans supplement, rather than replace, review and platform testing.
