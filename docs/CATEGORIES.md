# Download categories

Create and rename category labels in Settings. Assign a category in a selected download's details and use the toolbar filter for a category, Uncategorized or All categories. Labels work with native HTTP, native torrents, optional engine transfers and retained history records. Removing a category clears its assignments; it never removes a transfer, changes its source, or renames/moves/deletes any downloaded file.

Categories and assignments persist across restart in `categories.json` under the application data directory. Limits are 32 categories, 48 visible characters per name, 2048 assignments and 256 KiB of saved state. Category names are unique without case distinctions. Defaults contain no categories or assignments. Invalid/oversized/nonregular state is retained; only category controls become unavailable and ordinary downloads remain usable.

Owner-only `GET /api/categories` returns version 1 state with a revision, categories and assignments. A POST is limited to 2 KiB and uses action `create`, `rename`, `delete` or `assign`, plus the revision the user reviewed. Stale writes return 409; another pending save returns 503 instead of accumulating writer requests. Assignment requires an existing engine transfer or retained history record. Empty category ID clears a label. Bearer, Host and Origin protections also apply; browser pairing tokens and add-ons do not gain access.

Each mutation prepares a separate snapshot, writes, flushes and closes a temporary file, then replaces the saved state before exposing the new snapshot. Failed saves leave the previous category state active. Status reads use the previous snapshot during disk writes instead of waiting for filesystem I/O. Editing a name retains its original reviewed revision; a concurrent edit must be refreshed/reset rather than silently overwritten.

Local evidence covers owner/Origin/input refusal, assignments to real native transfers, lost-update prevention, failed-write preservation, invalid-state retention, independent snapshots and reads during a pending save. A real browser exercise covers create, assignment, category filters and empty states, rename, deletion and retained transfers. A complete process restart preserved categories/assignments and the completed file's SHA-256; a damaged-category process test still downloaded exact HTTP fixture bytes. Desktop/narrow-window controls were inspected with the approved layout/icon preserved. Automatic categorization rules, grouping queues and file moves/rename remain separate work.
