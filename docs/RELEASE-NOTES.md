Experimental local download manager, 0.1.0-dev. Browser UI with native MIT-licensed Rain BitTorrent support and an optional aria2 engine for other protocols. Includes transfer controls, live progress, batch link import, persistent history, SHA-256 verification, speed limits a permission-gated tracker feed, and paired browser-extension packages. No native desktop shell or automatic engine installation. Only Windows x64 has runtime evidence; other targets are cross-compilation candidates. Unsigned development artifacts, not Microsoft Store packages. See release report before use.
